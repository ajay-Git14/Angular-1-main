# Topic 4: Pipes and Custom Pipes

## Goal

Understand Angular Pipes, learn how to transform and format data before displaying it to users, and create custom pipes for reusable business formatting logic.

---

# What

Pipes transform data in Angular templates.

Without Pipes:

```text
Raw Data
     ↓
Displayed Directly
```

With Pipes:

```text
Raw Data
     ↓
Pipe Transformation
     ↓
User Friendly Output
```

Example:

```text
deepak kumar
```

Using UpperCase Pipe:

```text
DEEPAK KUMAR
```

---

# Real-Life Analogy

Imagine a water treatment plant.

```text
Raw Water
      ↓
Treatment Process
      ↓
Clean Drinking Water
```

Similarly:

```text
Raw Data
      ↓
Pipe
      ↓
Formatted Data
```

Better User Experience

## Lab 16: Generate Pipe

```bash
ng g p status
```

Generated:

```text
status.pipe.ts
```

---

## Lab 17: Create Custom Pipe

```typescript
import {

Pipe,

PipeTransform

}
from '@angular/core';

@Pipe({

name:'status'

})

export class StatusPipe
implements PipeTransform{

transform(
value:string
){

return value.toUpperCase();

}

}
```

---

## Lab 18: Use Custom Pipe

### Template

```html
{{'open' | status}}
```

Output:

```text
OPEN
```
