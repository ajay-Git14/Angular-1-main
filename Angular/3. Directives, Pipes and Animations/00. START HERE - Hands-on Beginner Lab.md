# Module 03: Filter a list and format displayed values

## Goal
Use Angular control flow and built-in pipes in a real price list.

## Steps
1. Run `ng generate component product-list`.
2. In the new component TypeScript file import `CurrencyPipe` from `@angular/common`.
3. Add `CurrencyPipe` to the component's `imports` array and define:

```ts
products = [
  { id: 1, name: 'Notebook', price: 120 },
  { id: 2, name: 'Pen', price: 15 },
  { id: 3, name: 'Bag', price: 850 }
];
showProducts = true;
```

4. Replace its generated HTML with:

```html
<button (click)="showProducts = !showProducts">Show / hide products</button>
@if (showProducts) {
  <ul>
    @for (product of products; track product.id) {
      <li>{{ product.name }} — {{ product.price | currency:'INR' }}</li>
    } @empty {
      <li>No products found.</li>
    }
  </ul>
} @else {
  <p>Products are hidden.</p>
}
```

5. Import and render `ProductList` from your root component, following Module 02's parent/child steps.

## Expected result
Three INR prices appear; the button toggles the whole list.

## Troubleshooting
- **No pipe found:** add `CurrencyPipe` to the component imports.
- **Unknown @for syntax:** ensure your project uses a modern Angular release supporting built-in control flow.
- **List not visible:** verify you added the component's selector to root HTML.

## Practice
Add a fourth product; set `products = []` temporarily and inspect the empty state. For animations, refer to the Angular version-specific official guide before choosing an API.
