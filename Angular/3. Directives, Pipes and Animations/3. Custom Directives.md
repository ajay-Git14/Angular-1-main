# Technology: Angular

# Module 3: Directives, Pipes and Animations

# Topic 3: Custom Directives

## Duration

1 Hour

## Goal

Understand how to create Custom Directives in Angular, learn how Angular manipulates DOM elements using directives, and build reusable behavior that can be applied across enterprise applications.

---

# What

Angular provides built-in directives:

```text
ngClass

ngStyle

@if

@for
```

But enterprise applications often need custom behavior.

Examples:

```text
Highlight VIP Residents

Auto Uppercase Input

Restrict Invalid Characters

Role-Based Visibility

Hover Effects
```

For these requirements, Angular allows us to create:

```text
Custom Directives
```

---

# Real-Life Analogy

Imagine a society security guard.

Default Rules:

```text
Visitor Entry

Resident Entry
```

Custom Society Rules:

```text
VIP Parking

Guest Restrictions

Special Access
```

Similarly:

```text
Angular Built-In Directives
        +
Custom Business Rules
```

---

# Why

Without Custom Directives:

```text
Duplicate Code

Repeated Logic

Poor Maintainability

Large Components
```

---

With Custom Directives:

```text
Reusable Behavior

Cleaner Components

Centralized Logic

Enterprise Scalability
```

---

# How It Works

```text
Directive
      ↓
Attach To Element
      ↓
Modify Behavior
      ↓
Update UI
```

Example:

```html
<p appHighlight>

VIP Resident

</p>
```

Directive automatically applies behavior.

# ElementRef

## What

Provides access to actual DOM element.

---

## Lab 4: Inject ElementRef

```typescript
import {

ElementRef

}
from '@angular/core';

constructor(

private element:
ElementRef

){ }
```

---

## Lab 5: Change Background

```typescript
constructor(

private element:
ElementRef

){

this.element
.nativeElement
.style
.backgroundColor
=
'yellow';

}
```

Output:

```text
Yellow Background
```

# Renderer2

## Why Renderer2?

Avoid direct DOM manipulation.

Recommended Angular approach.

---

## Lab 6: Inject Renderer2

```typescript
constructor(

private element:
ElementRef,

private renderer:
Renderer2

){ }
```

---

## Lab 7: Apply Style

```typescript
this.renderer.setStyle(

this.element.nativeElement,

'color',

'blue'

);
```

Output:

```text
Blue Text
```

---

## Lab 8: Multiple Styles

```typescript
this.renderer.setStyle(

this.element.nativeElement,

'bold'

);
```

# HostListener

## What

Listens to events occurring on host element.

---

## Lab 9: Mouse Enter

```typescript
@HostListener(
'mouseenter'
)

onMouseEnter(){

console.log(
'Mouse Enter'
);

}
```

---

## Lab 10: Hover Highlight

```typescript
@HostListener(
'mouseenter'
)

onMouseEnter(){

this.renderer.setStyle(

this.element.nativeElement,

'background',

'yellow'

);

}
```

---

## Lab 11: Mouse Leave

```typescript
@HostListener(
'mouseleave'
)

onMouseLeave(){

this.renderer.removeStyle(

this.element.nativeElement,

'background'

);

}
```

---

# HostBinding

## What

Binds properties directly to host element.

---

## Lab 12: First HostBinding

```typescript
@HostBinding(
'style.color'
)

textColor =
'red';
```

Output:

```text
Text Color Red
```

---

## Lab 13: Dynamic HostBinding

```typescript
@HostBinding(
'style.fontWeight'
)

fontWeight =
'bold';
```
