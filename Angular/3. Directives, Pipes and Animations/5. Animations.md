# What

Animations make Angular applications feel alive.

Without Animations:

```text id="3t2e6h"
Element Appears

Element Disappears

Instant Change
```

User experience feels abrupt.

---

With Animations:

```text id="8du2yq"
Smooth Appearance

Smooth Disappearance

Smooth Movement

Smooth State Changes
```

Applications become more professional.

---

# Real-Life Analogy

Imagine automatic doors at a shopping mall.

Without animation:

```text id="l1b0ij"
Door Closed
     ↓
Door Open
```

Instantly.

---

With animation:

```text id="sm8uwm"
Door Closed
     ↓
Door Slowly Opens
     ↓
Door Open
```

Much better experience.

Angular Animations work similarly.

# State Animation

## Lab 3: Create States

```typescript id="gx13dd"
trigger(

'boxAnimation',

[

state(

'open',

style({

height:'200px'

})

),

state(

'closed',

style({

height:'100px'

})

)

]

)
```

---

## Lab 4: Create Transition

```typescript id="ubppvr"
transition(

'open <=> closed',

animate('500ms')

)
```
