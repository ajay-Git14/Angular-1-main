## Goal

Understand Attribute Directives in Angular, learn how to dynamically change the appearance and behavior of HTML elements using `ngClass`, `ngStyle`, and other attribute directives.

---

# What

Directives are instructions that tell Angular how to modify HTML elements.

Angular Directives are categorized into:

```text
Component Directives

Attribute Directives

Structural Directives
```

Today's focus:

```text
Attribute Directives
```

Attribute Directives modify:

```text
Appearance

Behavior

Styles

CSS Classes
```

without changing the DOM structure.

---

# Real-Life Analogy

Imagine a person.

The person remains the same.

But attributes can change:

```text
Shirt Color

Hair Style

Badge

Role
```

Similarly:

```text
Button
     ↓
Blue Button

Green Button

Disabled Button

Highlighted Button
```

Same element.

Different attributes.

---

# Why

Without Attribute Directives:

```text
Manual DOM Manipulation

Complex JavaScript

Difficult Maintenance
```

---

With Attribute Directives:

```text
Dynamic Styling

Dynamic Classes

Cleaner Templates

Better User Experience
```

# How It Works

```text
Component Data
        ↓
Attribute Directive
        ↓
HTML Element
        ↓
Browser UI
```

Example:

```typescript
isActive = true;
```

↓

```html
<div [ngClass]="{'active': isActive}">
```

↓

```text
CSS Applied Dynamically
```

# Wrap-Up

## Key Takeaways

```text
Attribute Directives modify element behavior and appearance.

ngClass dynamically applies CSS classes.

ngStyle dynamically applies CSS styles.

Attribute Directives do not create or remove DOM elements.

Enterprise Angular applications heavily use ngClass and ngStyle.
```

---

# Interview Line

**Attribute Directives modify the appearance or behavior of existing DOM elements. Angular's ngClass and ngStyle directives are commonly used to apply dynamic classes and styles based on component state.**
