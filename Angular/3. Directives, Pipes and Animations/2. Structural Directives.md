## Goal

---

# What

Structural Directives change the structure of the DOM.

Unlike Attribute Directives:

```text id="8ps1h8"
Attribute Directives
      ↓
Modify Existing Elements
```

Structural Directives:

```text id="ccixp4"
Create Elements

Remove Elements

Repeat Elements

Switch Elements
```

---

## Real-Life Analogy

Imagine a theater.

If audience arrives:

```text id="h7h4wy"
Open Hall
```

If no audience:

```text id="fwbvfd"
Close Hall
```

If 100 audience members:

```text id="dwvzmd"
Create 100 Seats
```

Angular Structural Directives work similarly.

# Structural Directives vs Attribute Directives

| Feature      | Structural Directive | Attribute Directive |
| ------------ | -------------------- | ------------------- |
| DOM Creation | Yes                  | No                  |
| DOM Removal  | Yes                  | No                  |
| Styling      | No                   | Yes                 |
| Example      | @if                  | ngClass             |
| Example      | @for                 | ngStyle             |

# Wrap-Up

## Key Takeaways

```text id="8e8d8u"
Structural Directives modify DOM structure.

@if handles conditions.

@for handles loops.

@switch handles multiple conditions.

@empty handles empty collections.

Modern Angular prefers @if, @for and @switch.
```

---

# Interview Line

**Structural Directives are Angular directives that add, remove, or repeat DOM elements dynamically based on application state and data.**
