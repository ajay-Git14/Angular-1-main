# Component Styles
## Goal

Understand how Angular applies styles to Components, learn View Encapsulation, Component Scoped Styling, and implement maintainable enterprise styling strategies.

---

# What

Component Styles allow Angular developers to apply CSS to a specific Component.

Each Component can have:

```text
HTML Template

TypeScript Logic

CSS Styling
```

Example:

```text
Header Component
      ↓
Header Style

Dashboard Component
      ↓
Dashboard Style

Complaint Component
      ↓
Complaint Style
```

Each component can have its own styling.

---

# Real-Life Analogy

Imagine apartments in a society.

```text
Flat A
    ↓
Blue Paint

Flat B
    ↓
Green Paint

Flat C
    ↓
Yellow Paint
```

Painting one flat should not affect other flats.

Similarly:

```text
Header Component CSS
       ↓
Should Not Affect
       ↓
Dashboard Component
```

Angular provides this isolation using View Encapsulation.

With Component Styles:

Enterprise Scalability

# View Encapsulation

## What Is View Encapsulation?

Angular mechanism that controls style isolation.

---

## Types

```text
Emulated

```

---

# Emulated Encapsulation

## Lab 6: Default Angular Behavior

### Component

```typescript
@Component({

 encapsulation:
 ViewEncapsulation.Emulated

})
```

Default Angular mode.

---

### Behavior

```text
Header CSS
     ↓
Header Only

Dashboard CSS
     ↓
Dashboard Only
```

Recommended.

# Enterprise Styling Strategy

## Recommended Structure

```text
Component CSS

Reusable CSS Classes

Theme Variables

Minimal Global CSS

Encapsulation Enabled
```

---

## Avoid

```text
Large Global Stylesheets

Duplicate CSS

Inline Styling Everywhere

ViewEncapsulation.None Abuse
```

# Wrap-Up

## Key Takeaways

```text
Angular supports Component-Level Styling.

styles provides inline styles.

styleUrl provides external CSS.

View Encapsulation isolates styles.

Emulated is Angular default.

ShadowDom provides strongest isolation.

None removes isolation.

Enterprise applications use Component Scoped Styling.
```
