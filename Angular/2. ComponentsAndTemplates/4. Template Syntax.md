# Topic 4: Template Syntax
## Goal

Understand Angular Template Syntax, how Angular templates communicate with component data, and how dynamic UI is rendered using expressions, statements, references, and template features.

---

# What

Template Syntax is the language Angular uses inside HTML templates to communicate with Component data and logic.

Normal HTML:

```html
<h1>Welcome</h1>
```

Static content.

---

Angular Template:

```html
<h1>{{title}}</h1>
```

Dynamic content.

---

## Real-Life Analogy

Imagine a TV news channel.

Template:

```text
News Screen Layout
```

Component:

```text
Latest News Data
```

Angular:

```text
Component Data
        ↓
Template
        ↓
Screen
```

---

# Why

Without Template Syntax:

```text
Static UI

Manual DOM Manipulation

Complex JavaScript
```

---

With Template Syntax:

```text
Dynamic UI

Automatic Updates

Cleaner Development
```

---

# How It Works

```text
Component
      ↓
Properties
      ↓
Template Syntax
      ↓
Browser UI
```

Example:

```typescript
title = "Angular Training";
```

↓

```html
<h1>{{title}}</h1>
```

↓

```text
Angular Training
```

### Common problems and fixes

| Symptom | First check |
|---|---|
| `ng` not recognized | Node.js/CLI installation and terminal PATH; run `ng version` |

| Unknown custom element | Import the child class in the root standalone component's `imports`; match its selector |
| Property or method missing | Match class member names and template spelling exactly |
| Nothing changes on screen | Ensure the edited HTML is the file referenced by the child's `templateUrl`; save changes |
