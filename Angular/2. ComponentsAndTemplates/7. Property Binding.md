## Goal

Understand Property Binding in Angular, learn how component data dynamically updates HTML element properties, and build responsive user interfaces using Angular's one-way data flow.

---

# What

Property Binding allows Angular to send data:

```text
Component
      ↓
HTML Element Property
```

Syntax:

```html
[property]="value"
```

Example:

```html
<img [src]="imageUrl">
```

Angular updates the image source dynamically.

---

## Real-Life Analogy

Imagine a Smart TV.

```text
Remote Control
      ↓
TV Settings
      ↓
Screen Updates
```

Similarly:

```text
Component Property
      ↓
Property Binding
      ↓
HTML Element Updates
```

# Property Vs Attribute

## Attribute

HTML Definition

```html
<input value="Angular">
```

Initial value only.

---

## Property

Runtime value

```html
<input [value]="courseName">
```

Dynamic value.

## Beginner practical — Property binding

**Prerequisite:** Complete [Module 01 workstation setup](../1.%20Fundamentals/00.%20START%20HERE%20-%20Hands-on%20Beginner%20Lab.md) and open the Angular workspace in VS Code.

**Goal:** Build a visible property binding example that you can explain.

1. Open VS Code Terminal in the folder containing `angular.json` and run `ng generate component button-state`.
2. Open the generated component's HTML file in `src/app/button-state/` (the filename is given by `templateUrl`) and insert:

```html
<button [disabled]="saving" (click)="saving = true">Save</button><button (click)="saving = false">Reset</button>
```

3. **TypeScript change:** Add saving = false to the class. Keep the existing class, `@Component`, and other imports.
4. Import this generated standalone component into the root component's decorator `imports` and render `<app-button-state></app-button-state>` in root HTML (use the generated selector if it differs).
5. Run `ng serve --open`, save files, and click or type in the page controls.

**Expected result:** The browser shows the new example, and the UI changes when you interact with it.

**Debugging:** Unknown element? Check root `imports` and selector. Unknown property? Check spelling in the class. Unknown `ngModel`? Check `FormsModule` import. No result? Confirm the edited HTML matches the component's `templateUrl`.

**Your turn:** Change initial values; add a second control; predict then verify the browser result. Record screenshot and a 30-second explanation.

**Memory hook:** `{{ }}` displays data, `[property]` pushes values into element properties, `(event)` responds to input, `[(ngModel)]` synchronizes both directions when FormsModule is available.

**Reference:** https://angular.dev/guide/templates/binding
