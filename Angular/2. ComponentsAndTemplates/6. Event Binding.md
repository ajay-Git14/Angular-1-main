# What

Event Binding allows Angular to respond to user actions.

Examples:

```text
Button Click

Mouse Hover

Key Press

Form Submit

Input Change
```

Without Event Binding:

```text
Application Is Static
```

With Event Binding:

```text
Application Becomes Interactive
```

---

## Real-Life Analogy

Imagine a doorbell.

```text
Person Presses Bell
        ↓
Bell Rings
```

Event:

```text
Bell Press
```

Action:

```text
Bell Sound
```

Angular works similarly.

```text
User Action
      ↓
Event
      ↓
Component Method
      ↓
UI Update
```

---

# Why

Without Event Binding:

```text
No User Interaction

No Form Submission

No Dynamic Behavior
```

---

With Event Binding:

```text
Interactive UI

Dynamic Forms

User Actions Processed

Business Logic Executed
```

# How It Works

```text
User Action
      ↓
Event
      ↓
Angular Template
      ↓
Component Method
      ↓
UI Update
```

Example:

```html
<button
(click)="save()">

Save

</button>
```

↓

```typescript
save(){

   console.log(
      "Saved"
   );

}
```

## Beginner practical — Event binding

**Prerequisite:** Complete [Module 01 workstation setup](../1.%20Fundamentals/00.%20START%20HERE%20-%20Hands-on%20Beginner%20Lab.md) and open the Angular workspace in VS Code.

**Goal:** Build a visible event binding example that you can explain.

1. Open VS Code Terminal in the folder containing `angular.json` and run `ng generate component click-counter`.
2. Open the generated component's HTML file in `src/app/click-counter/` (the filename is given by `templateUrl`) and insert:

```html
<button (click)="increase()">Add</button><p>{{ count }}</p><button (click)="count = 0">Reset</button>
```

3. **TypeScript change:** Add count = 0 and increase() { this.count++; } to the class. Keep the existing class, `@Component`, and other imports.
4. Import this generated standalone component into the root component's decorator `imports` and render `<app-click-counter></app-click-counter>` in root HTML (use the generated selector if it differs).
5. Run `ng serve --open`, save files, and click or type in the page controls.

**Expected result:** The browser shows the new example, and the UI changes when you interact with it.

**Debugging:** Unknown element? Check root `imports` and selector. Unknown property? Check spelling in the class. Unknown `ngModel`? Check `FormsModule` import. No result? Confirm the edited HTML matches the component's `templateUrl`.

**Your turn:** Change initial values; add a second control; predict then verify the browser result. Record screenshot and a 30-second explanation.

**Memory hook:** `{{ }}` displays data, `[property]` pushes values into element properties, `(event)` responds to input, `[(ngModel)]` synchronizes both directions when FormsModule is available.

**Reference:** https://angular.dev/guide/templates/binding
