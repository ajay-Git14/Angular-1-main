# What

Two Way Binding allows data to flow in both directions:

```text
Component
     ↕
Template
```

Meaning:

```text
Component Changes
        ↓
UI Updates

User Changes UI
        ↓
Component Updates
```

Both remain synchronized.

---

## Real-Life Analogy

Imagine Google Docs.

When you type:

```text
Keyboard
    ↓
Document Updates
```

When another user updates:

```text
Document Updates
    ↓
Screen Updates
```

Both sides stay synchronized.

Angular Two Way Binding works similarly.

---

# Why

Without Two Way Binding:

```text
Read Input Manually

Update Component Manually

Update UI Manually
```

More code.

---

With Two Way Binding:

```text
Automatic Synchronization

Cleaner Code

Better User Experience

Faster Development
```

---

```text
      ↓

```

Only one direction.

## Two Way Binding

```text

      ↕
```

Both directions.

## Beginner practical — Two-way binding

**Prerequisite:** Complete [Module 01 workstation setup](../1.%20Fundamentals/00.%20START%20HERE%20-%20Hands-on%20Beginner%20Lab.md) and open the Angular workspace in VS Code.

**Goal:** Build a visible two-way binding example that you can explain.

1. Open VS Code Terminal in the folder containing `angular.json` and run `ng generate component name-editor`.
2. Open the generated component's HTML file in `src/app/name-editor/` (the filename is given by `templateUrl`) and insert:

```html
<label>Name <input name="name" [(ngModel)]="name"></label><p>Hello {{ name }}</p>
```

3. **TypeScript change:** Add name = 'Asha' and import FormsModule from @angular/forms into this standalone component's @Component imports. Keep the existing class, `@Component`, and other imports.
4. Import this generated standalone component into the root component's decorator `imports` and render `<app-name-editor></app-name-editor>` in root HTML (use the generated selector if it differs).
5. Run `ng serve --open`, save files, and click or type in the page controls.

**Expected result:** The browser shows the new example, and the UI changes when you interact with it.

**Debugging:** Unknown element? Check root `imports` and selector. Unknown property? Check spelling in the class. Unknown `ngModel`? Check `FormsModule` import. No result? Confirm the edited HTML matches the component's `templateUrl`.

**Your turn:** Change initial values; add a second control; predict then verify the browser result. Record screenshot and a 30-second explanation.

**Memory hook:** `{{ }}` displays data, `[property]` pushes values into element properties, `(event)` responds to input, `[(ngModel)]` synchronizes both directions when FormsModule is available.

**Reference:** https://angular.dev/guide/templates/binding
