# Topic 5: Data Binding
## Goal

Understand Data Binding in Angular, how data flows between Components and Templates, and how Angular keeps UI synchronized with application data.

---

# What

Data Binding is the mechanism that connects:

```text
Component Data
        ↔
Template UI
```

It allows Angular to automatically update the UI whenever component data changes.

---

## Real-Life Analogy

Imagine a Digital Scoreboard.

```text
Cricket Score Changes
          ↓
Scoreboard Updates Automatically
```

Nobody manually changes the scoreboard.

Similarly:

```text
Component Data Changes
          ↓
Angular Updates UI Automatically
```

---

# Why

Without Data Binding:

```text
Manual DOM Manipulation

Complex JavaScript

Error Prone Development

Poor Maintainability
```

---

With Data Binding:

```text
Automatic UI Updates

Cleaner Code

Better Productivity

Enterprise Scalability
```

---

# How It Works

```text
Component
      ↓
Data Binding
      ↓
Template
      ↓
Browser
```

Example:

```typescript
title = "Angular Training";
```

↓

```html
<h1>{{title}}</h1>
```

↓

```text
Angular Training
```

---

---

# Types of Data Binding

## 1. Interpolation Binding

```html
{{title}}
```

Displays component data.

---

## 2. Property Binding

```html
<img [src]="imageUrl">
```

Updates HTML properties.

---

## 3. Event Binding

```html
<button (click)="save()">
```

Captures user actions.

---

## 4. Two-Way Binding

```html
<input [(ngModel)]="name">
```

Synchronizes data in both directions.

## Beginner practical — Data binding

**Prerequisite:** Complete [Module 01 workstation setup](../1.%20Fundamentals/00.%20START%20HERE%20-%20Hands-on%20Beginner%20Lab.md) and open the Angular workspace in VS Code.

**Goal:** Build a visible data binding example that you can explain.

1. Open VS Code Terminal in the folder containing `angular.json` and run `ng generate component binding-demo`.
2. Open the generated component's HTML file in `src/app/binding-demo/` (the filename is given by `templateUrl`) and insert:

```html
<h2>{{ title }}</h2><input [value]="title" readonly><button (click)="title = 'Updated'">Change</button>
```

3. **TypeScript change:** Add title = 'Angular' to the class. Keep the existing class, `@Component`, and other imports.
4. Import this generated standalone component into the root component's decorator `imports` and render `<app-binding-demo></app-binding-demo>` in root HTML (use the generated selector if it differs).
5. Run `ng serve --open`, save files, and click or type in the page controls.

**Expected result:** The browser shows the new example, and the UI changes when you interact with it.

**Debugging:** Unknown element? Check root `imports` and selector. Unknown property? Check spelling in the class. Unknown `ngModel`? Check `FormsModule` import. No result? Confirm the edited HTML matches the component's `templateUrl`.

**Your turn:** Change initial values; add a second control; predict then verify the browser result. Record screenshot and a 30-second explanation.

**Memory hook:** `{{ }}` displays data, `[property]` pushes values into element properties, `(event)` responds to input, `[(ngModel)]` synchronizes both directions when FormsModule is available.

**Reference:** https://angular.dev/guide/templates/binding
