# Topic 3: NgModules and Custom One for Your Code Separation

## Goal

Understand NgModules, learn how Angular organizes code into modules, and build scalable enterprise applications using feature-based code separation.

---

# What

NgModule is a mechanism used to organize Angular code into logical groups.

Without Modules:

```text id="6y4wpm"
All Components

All Services

All Pipes

Inside One Folder
```

---

Problems:

```text id="5jnh6j"
Difficult Maintenance

Poor Scalability

Code Duplication
```

---

With Modules:

```text id="y79k7h"
Application

├── Complaint Module
├── Resident Module
├── Reports Module
├── Settings Module
└── Shared Module
```

---

# NgModules vs Standalone

| NgModules                  | Standalone               |
| -------------------------- | ------------------------ |
| Traditional Angular        | Modern Angular           |
| Module Based               | Component Based          |
| More Configuration         | Less Configuration       |
| Enterprise Legacy Projects | Modern Angular Projects  |
| Still Widely Used          | Recommended For New Apps |
