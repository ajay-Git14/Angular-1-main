# Technology: Angular

# Module 8: Advanced Angular Features

# Topic 1: @ViewChild and Its Usage

## Goal

Understand @ViewChild in Angular, learn how a parent component can access child components and DOM elements, and implement enterprise-level component communication patterns.

---

# What

`@ViewChild` allows a Parent Component to directly access:

```text
Child Components

HTML Elements

Directives

Templates
```

Without @ViewChild:

```text
Parent Component

Cannot Directly Access

Child Component Internals
```

---

With @ViewChild:

```text
Parent Component
       ↓
Direct Access
       ↓
Child Component
```

---

# Real-Life Analogy

Imagine a manager and employee.

Without direct access:

```text
Manager
   ↓
Request
   ↓
Response
```

---

With direct access:

```text
Manager
    ↓
Direct Communication
    ↓
Employee
```

Similarly:

```text
Parent Component
      ↓
@ViewChild
      ↓
Child Component
```

---

# Why

Without @ViewChild:

```text
Complex Communication

Extra Events

More Boilerplate Code
```

---

With @ViewChild:

```text
Direct Access

Cleaner Code

Better Component Control
```

---

# How It Works

```text
Parent Component

@ViewChild

Child Component Reference
        ↓
Access Methods & Properties
```

# Wrap-Up

## Key Takeaways

```text
@ViewChild provides direct access to child components.

@ViewChild can access HTML elements.

ElementRef provides DOM access.

Parent components can call child methods.

ngAfterViewInit is the correct lifecycle hook.

Enterprise applications heavily use ViewChild.
```
