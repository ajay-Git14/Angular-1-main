# Topic 2: @ContentChild and Its Usage

## Goal

Understand Content Projection and @ContentChild, learn how Angular accesses projected content, and build reusable enterprise components with customizable UI sections.

---

# What

`@ContentChild` allows a component to access content projected from its parent component.

Unlike `@ViewChild`:

```text
@ViewChild
     ↓
Accesses Own View
```

---

```text
@ContentChild
       ↓
Accesses Projected Content
```

---

# Real-Life Analogy

Imagine a hotel conference hall.

Hotel provides:

```text

Lighting

Sound System
```

Customer brings:


Hotel can interact with customer content.


# ViewChild vs ContentChild

| ViewChild              | ContentChild          |
| ---------------------- | --------------------- |
| Own View               | Projected Content     |
| Child Component Access | Parent Content Access |
| ngAfterViewInit        | ngAfterContentInit    |
| Internal View          | External Content      |
