# Topic 2: Unit Testing Components and Services

## Goal

Understand Unit Testing of Angular Components and Services, learn how to test UI behavior, business logic, service methods, and dependencies, and build enterprise-grade Angular applications with confidence.

---

## What

Unit Testing verifies individual Angular units such as:

```text
Components

Services

Methods

Properties

Business Logic
```

---

Example:

```text
Complaint Form Component
          ↓
Test Independently
```

---

```text
Complaint Service
         ↓
Test Independently
```

---

## Real-Life Analogy

Imagine testing a car.

Instead of testing the entire car first:

```text
Engine Test

Brake Test

Battery Test

Wheel Test
```

Each part is verified separately.

Similarly:

```text
Component Test

Service Test

Method Test
```

before testing the entire application.

---

## Why

Without Unit Testing:

```text
Hidden Bugs

Difficult Refactoring

Low Confidence

Production Issues
```

---

With Unit Testing:

```text
Reliable Code

Safer Changes

Faster Development

Higher Quality
```

---

## How It Works

```text
Component Or Service
          ↓
Test Case
          ↓
Expected Result
          ↓
Pass / Fail
```

# Mock Services

## Why?

Avoid real dependencies.

---

Without Mock:

```text
Test
 ↓
Real API
```

---

Problem:

```text
Slow

Unstable

External Dependency
```

---

With Mock:

```text
Test
 ↓
Fake Service
```

---

Reliable.

---
