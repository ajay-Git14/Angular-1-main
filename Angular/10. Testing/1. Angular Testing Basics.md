# Topic 1: Angular Testing Basics

## Goal

Understand Angular Testing fundamentals, learn why testing is critical in enterprise applications, and build confidence in writing reliable, maintainable, and automated tests.

---

## What

Testing is the process of verifying that an application works as expected.

Without Testing:

```text
Developer Writes Code
         ↓
Deploy To Production
         ↓
Unexpected Bugs
```

---

With Testing:

```text
Developer Writes Code
         ↓
Run Tests
         ↓
Verify Functionality
         ↓
Deploy Safely
```

---

## Real-Life Analogy

Imagine building a new car.

Without Testing:

```text
Build Car
    ↓
Sell Car
    ↓
Brakes Fail
```

---

With Testing:

```text
Build Car
    ↓
Test Brakes
    ↓
Test Engine
    ↓
Test Safety
    ↓
Sell Car
```

Similarly:

```text
Write Code
      ↓
Test Code
      ↓
Deploy Code
```

---

# Types Of Testing

## Unit Testing

Tests a single unit.

Example:

```text
Calculate Total

Validate Form

Check Button Click
```

---

Scope:

```text
Smallest Testing Unit
```

---

## Integration Testing

Tests multiple units together.

Example:

```text
Component
      ↓
Service
      ↓
API
```

---

Verify:

```text
Modules Work Together
```

---

## End-To-End Testing (E2E)

Tests complete user journey.

Example:

```text
Login
 ↓
Dashboard
 ↓
Create Complaint
 ↓
Logout
```

---

Simulates real users.

# Mocking Concept

## Why?

Avoid calling real systems.

---

Without Mock:

```text
Test
 ↓
Real API
```

---

Problem:

```text
Slow

Unstable

External Dependency
```

---

With Mock:

```text
Test
 ↓
Fake Response
```

---

Fast and reliable.
