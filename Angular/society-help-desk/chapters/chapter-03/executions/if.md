# @if / @else — Live Execution Detail

**Curriculum:** Chapter 03 → Structural Directives → @if / @else → Execution
**Status:** Interactive Angular example implemented in the shared Society Help Desk application; local compiler/browser verification still required.

## Problem and learner story
Create and remove a resident alert based on visibility. We use fictional Society Help Desk data for the examples.

## Memory hook
**@if = the door opens only when needed.**

## Open and execute the demo
1. From repository root, run:

       cd Angular/society-help-desk
       npm install
       npm run test:lab
       npm run build
       npm start

2. Open http://localhost:4200/chapters/03/structural-directives/if
3. **Try this:** Show or hide the alert.
4. **Expected result:** The alert element appears or is removed from the DOM.
5. Click Reset and repeat. Explain how the result changes.

## Relevant instructional code
This snippet comes from the Module 03 learning catalogue. The real executable implementation is in src/lab/, not in this Markdown document.

~~~typescript
@if (showAlert()) { <p>Water service alert</p> } @else { <p>No active alert</p> }
~~~
