**Curriculum:** Chapter 03 → Animations → Scale transition → Execution
**Status:** Interactive Angular example implemented in the shared Society Help Desk application; local compiler/browser verification still required.

## Problem and learner story
Grow and shrink a priority indicator. We use fictional Society Help Desk data for the examples.

## Memory hook
**scale() zooms without changing the document layout.**

## Open and execute the demo
1. From repository root, run:

       cd Angular/society-help-desk
       npm install
       npm run test:lab
       npm run build
       npm start

2. Open http://localhost:4200/chapters/03/animations/scale
3. **Try this:** Toggle zoom.
4. **Expected result:** The indicator scales smoothly.
5. Click Reset and repeat. Explain how the result changes.
