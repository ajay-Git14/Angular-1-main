## Goal

# What

Observables are the foundation of RxJS.

They represent:

```text
A Stream Of Data
Over Time
```

Examples:

```text
API Responses

User Clicks

Keyboard Input

Notifications

Stock Prices
```

---

# Real-Life Analogy

Imagine a YouTube Live Stream.

```text
Broadcaster
      ↓
Live Stream
      ↓
Viewers
```

Whenever new content arrives:

```text
All Viewers Receive It
```

Similarly:

```text
Observable
      ↓
Subscriber
      ↓
Receive Data
```

## What

Observer receives data emitted by Observable.

---

```typescript
);

}

});
```

# BehaviorSubject

## What

Stores latest value.

---

## Lab 11

```typescript
import {

BehaviorSubject

}
from 'rxjs';

new BehaviorSubject(

);
```

---

# Subscriber 1

```typescript

.subscribe(

);
```

Output:

```text

```

Immediately receives current value.

---

## Update Value

```typescript

'Deepak'
);
```

---

Output:


---

# Subject vs BehaviorSubject

| Subject                             | BehaviorSubject                 |
| ----------------------------------- | ------------------------------- |
| No Initial Value                    | Initial Value Required          |
| No Stored Value                     | Stores Latest Value             |
| New Subscriber Misses Previous Data | New Subscriber Gets Latest Data |
| Event Broadcasting                  | State Management                |

## Key Takeaways

