## Goal

Understand Angular Effects, learn how to react to Signal changes automatically, and implement side effects such as logging, API calls, local storage updates, and analytics tracking.

---

# What

Effects allow Angular to execute code automatically whenever a Signal changes.

Without Effect:

```text
Signal Changes
      ↓
Developer Manually Executes Logic
```

---

With Effect:

```text
Signal Changes
      ↓
Effect Automatically Executes
```

---

# Real-Life Analogy

Imagine a smoke detector.

```text
Smoke Appears
      ↓
Alarm Automatically Sounds
```

Nobody manually starts the alarm.

Similarly:

```text
Signal Changes
      ↓
Effect Runs Automatically
```

---

With Effects:

# What Is A Side Effect?

A side effect is anything outside normal UI rendering.

Examples:

```text
Logging

API Calls

Analytics

Local Storage

Notifications

Tracking
```

---

# Good Effect Usage

```text
Logging

Persistence

Monitoring

Analytics

External Integrations
```

---

# Avoid In Effects

```text
Complex Business Logic

State Loops

Heavy Computation
```

Use:

```text
Computed Signals
```

for calculations.

---

# Effect vs Computed Signal

| Effect          | Computed            |
| --------------- | ------------------- |
| Side Effects    | Derived State       |
| Logging         | Calculations        |
| API Calls       | Data Transformation |
| Local Storage   | Dashboard Metrics   |
| No Return Value | Returns Value       |
