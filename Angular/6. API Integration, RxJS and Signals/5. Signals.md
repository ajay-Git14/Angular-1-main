## Goal

Understand Angular Signals, learn Angular's modern reactive state management approach, and build high-performance Angular applications with simpler and more predictable state handling.

# What

Signals are Angular's modern reactive state mechanism.

A Signal stores a value and automatically updates everything that depends on it.

Traditional Angular:

```text
Variable Changes
        ↓
Change Detection
        ↓
UI Update
```

---

With Signals:

```text
Signal Changes
       ↓
Angular Knows Exactly
What Changed
       ↓
Only Required UI Updates
```

---

# Real-Life Analogy

Imagine a digital temperature display.

```text
Temperature Sensor
        ↓
Temperature Changes
        ↓
Display Updates Automatically
```

Nobody manually refreshes the display.

Similarly:

```text
Signal Value
      ↓
Changes
      ↓
UI Updates Automatically
```

# update()

## What

Updates value based on previous value.

---

## Lab 6

```typescript
count.update(

value =>

value + 1

);
```

---

Cleaner approach.

---

# Difference Between set() and update()

| set()         | update()               |
| ------------- | ---------------------- |
| Direct Value  | Uses Existing Value    |
| Replace State | Modify State           |
| count.set(5)  | count.update(v => v+1) |

# Signals vs BehaviorSubject

| Signals             | BehaviorSubject     |
| ------------------- | ------------------- |
| Angular Native      | RxJS                |
| No Subscribe        | Subscribe Required  |
| Simpler Syntax      | More Boilerplate    |
| Automatic Tracking  | Manual Subscription |
| Better For UI State | Better For Streams  |

---

# Signals vs RxJS

| Signals          | RxJS                |
| ---------------- | ------------------- |
| State Management | Data Streams        |
| UI Reactivity    | Async Processing    |
| Simple State     | Complex Async Logic |
| Angular Native   | RxJS Library        |

## Key Takeaways

```text

Signal values are read using ().

set() replaces state.

update() modifies existing state.

Signals automatically update UI.

Signals reduce RxJS complexity for UI state.
```
