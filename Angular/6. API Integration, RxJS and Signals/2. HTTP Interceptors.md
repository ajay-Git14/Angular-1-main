# Topic 2: HTTP Interceptors

## Goal

Understand HTTP Interceptors, learn how Angular intercepts requests and responses globally, and implement enterprise-level authentication, logging, error handling, and security patterns.

---

# What

HTTP Interceptors sit between Angular and the backend API.

Without Interceptor:

```text
Component
     ↓
HttpClient
     ↓
API
```

---

With Interceptor:

```text
Component
     ↓
HttpClient
     ↓
Interceptor
     ↓
API
```

Interceptor can:

```text
Modify Requests

Modify Responses

Add Tokens

Handle Errors

Log Requests
```

---

# Real-Life Analogy

Imagine airport security.

Passenger:

```text
Passenger
     ↓
Security Check
     ↓
Board Flight
```

Security validates everything.

Similarly:

```text
HTTP Request
      ↓
Interceptor
      ↓
Backend API
```

Interceptor validates and modifies requests.

---

# Why

Without Interceptors:

```text
Duplicate Code

Repeated Token Logic

Repeated Error Handling

Repeated Logging
```

---

With Interceptors:

```text
Centralized Logic

Reusable Security

Global Error Handling

Cleaner Services
```
