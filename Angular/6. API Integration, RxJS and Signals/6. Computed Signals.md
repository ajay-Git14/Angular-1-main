# Topic 6: Computed Signals

## Goal

Understand Computed Signals, learn how Angular derives values automatically from existing Signals, and build efficient enterprise applications with calculated reactive state.

---

# What

Computed Signals create derived values from one or more Signals.

Instead of manually calculating values:

```text
Signal A
Signal B

Developer Calculates Result
```

Angular automatically calculates:

```text
Signal A
     ↓
Computed Signal
     ↓
Derived Result

Signal B
```

---

# Real-Life Analogy

Imagine a shopping cart.

```text
Product Price = 100

Quantity = 5
```

Total:

```text
100 × 5 = 500
```

When quantity changes:

```text
100 × 10 = 1000
```

Nobody manually recalculates.

Computed Signal automatically updates.

---

# Why

Without Computed Signals:

```text
Manual Calculations

Duplicate Logic

```

With Computed Signals:

```text
Automatic Calculations

Less Code

Better Performance
```

# Signals vs Computed Signals

| Signal         | Computed Signal   |
| -------------- | ----------------- |
| Stores State   | Derives State     |
| Writable       | Read Only         |
| set() Allowed  | set() Not Allowed |
| Source Data    | Calculated Data   |
| Manual Updates | Automatic Updates |
