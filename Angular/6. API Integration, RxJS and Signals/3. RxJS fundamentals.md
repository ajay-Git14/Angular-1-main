# switchMap()

## What

Cancels previous request and uses latest.

---

# Search Box Example

```text
User Types A
        ↓

        ↓
Use Latest Request
```

# mergeMap()

## What

Runs multiple requests simultaneously.

---

## Lab 10

```typescript
orders$

.pipe(

mergeMap(

order =>

this.http.post(

'/api/order',

order

)

)

);
```

---

Used when:

```text
All Requests Must Complete
```

---

# switchMap vs mergeMap

| switchMap           | mergeMap         |
| ------------------- | ---------------- |
| Cancels Previous    | Keeps All        |
| Latest Request Only | All Requests Run |
| Search Boxes        | Batch Processing |
| Autocomplete        | Bulk Upload      |
