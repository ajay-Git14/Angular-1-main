# What

State is the current data of an application at any given moment.

Examples:

```text
Logged In User

Shopping Cart

Employee List

Complaint List

Theme Preference

Dashboard Statistics
```

# Real-Life Analogy

Imagine a bank account.

Current Balance:

```text
₹50,000
```

This balance represents the current state.

After Deposit:

```text
₹60,000
```

State changed.

Similarly:

```text
Application Data
       ↓
Current State
```

# Signal State vs BehaviorSubject State

| Signal                         | BehaviorSubject       |
| ------------------------------ | --------------------- |
| Angular Native                 | RxJS                  |
| Simpler                        | More Verbose          |
| No Subscription                | Subscription Required |
| UI State                       | Stream State          |
| Recommended For Modern Angular | Legacy/Common Pattern |

# Single Source Of Truth

## What

Bad Example:

```text

Component B User

Component C User
```

---

Good Example:

```text

      ↓
All Components Read Same Data
```

# Wrap-Up

## Key Takeaways

```text
State is current application data.

Component State belongs to one component.

Shared State belongs to multiple components.

Signals are ideal for modern Angular state.

Single Source Of Truth is critical.

Enterprise applications rely heavily on centralized state management.
```

# Interview Line

**State Management is the process of storing, updating, and sharing application data in a predictable and centralized way using mechanisms such as Signals, Computed Signals, Effects, and Stores.**
