> **Audience:** First-time Angular learners. **Goal:** Finish with a visible, working result rather than only reading theory.

## How to use this lab
1. Read the **Goal** and **Before you start** sections.
2. Type the commands yourself in **VS Code > Terminal > New Terminal** (do not type the dollar sign if shown in examples).
3. Copy each code block into the **exact filename** indicated. Save with **Ctrl+S**.
4. Keep `ng serve` running in one terminal. Use a second terminal for commands.
5. Check the **Expected result** after every small change. If it differs, use **Troubleshooting** before moving on.

## One-time workstation setup (complete once; reuse in every module)
- Install a Node.js **LTS release compatible with your chosen Angular release**: https://nodejs.org/
- Install Visual Studio Code: https://code.visualstudio.com/
- In VS Code, install **Angular Language Service** and **ESLint** extensions (ESLint requires project configuration).
- Run `node --version` and `npm --version`. Both should print versions.
- Install CLI: `npm install -g @angular/cli`; verify with `ng version`.

- Angular CLI prompts, filenames and generated test runner can vary by CLI version. Use the generated files in your project rather than guessing.

# Module 06: Load API data safely

## Goal
Call a public sample API, handle loading and errors, and display data with a signal.

## Steps
1. Add Angular HTTP support in `src/app/app.config.ts` by importing `provideHttpClient` from `@angular/common/http` and adding `provideHttpClient()` to the existing `providers` array. Do not delete existing providers.
2. Run `ng generate component post-list`.
3. In the component file import `HttpClient` from `@angular/common/http` and `inject, signal` from `@angular/core`.
4. Add these fields and method inside the component class:

```ts
private http = inject(HttpClient);
posts = signal<{ id: number; title: string }[]>([]);
loading = signal(false);
error = signal('');
load() {
  this.loading.set(true);
  this.error.set('');
  this.http.get<{ id: number; title: string }[]>('https://jsonplaceholder.typicode.com/posts')
    .subscribe({
      next: data => { this.posts.set(data.slice(0, 5)); this.loading.set(false); },
      error: () => { this.error.set('Unable to load posts.'); this.loading.set(false); }
    });
}
```

5. Replace the component template:

```html
<button (click)="load()">Load posts</button>
@if (loading()) { <p>Loading…</p> }
@if (error()) { <p role="alert">{{ error() }}</p> }
@for (post of posts(); track post.id) { <p>{{ post.title }}</p> }
```

6. Render this component from the root and click **Load posts** while online.

## Expected result
Five sample titles appear. In DevTools > Network you can see one GET request when the button is clicked.

## Troubleshooting
- **No provider for HttpClient:** verify `provideHttpClient()` is in app configuration.
- **Request blocked/offline:** inspect browser Network tab; an error message should appear.
- **TypeScript property error:** check imports and class braces.

## Practice
Display ten titles; explain the difference between the Observable (HTTP request) and signal (current UI state).

**Note:** This lab demonstrates one request explicitly triggered by a button. More complex long-lived streams may require lifecycle-aware teardown.
