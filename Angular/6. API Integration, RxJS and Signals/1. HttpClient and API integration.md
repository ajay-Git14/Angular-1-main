# Technology: Angular

# Module 6: API Integration, RxJS and Signals

# Topic 1: HttpClient and API Integration

## Goal

Understand how Angular communicates with backend APIs using HttpClient and learn how enterprise Angular applications perform CRUD operations with backend services.

---

# What

Most Angular applications do not store data locally.

Data usually comes from:

```text
Backend APIs

Microservices

Cloud Services

Databases
```

Angular communicates with them through:

```text
HttpClient
```

---


```text

      ↓
```

# GET Request

## What

Retrieve data from server.

---

### Service

```typescript

'https://api.com/complaints'

);
```

```typescript

.getComplaints()
```
