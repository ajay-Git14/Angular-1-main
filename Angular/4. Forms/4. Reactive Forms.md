## Goal

Understand Reactive Forms in Angular, learn how Angular manages forms through TypeScript code, and build scalable enterprise-grade forms using FormControl, FormGroup, FormArray, and FormBuilder.

---

# What

Reactive Forms are Angular forms where the form model is created and managed inside the Component class.

Unlike Template-Driven Forms:

```text
Template-Driven Forms
         ↓
Template Controls Form
```

Reactive Forms:

```text
Component
      ↓
Controls Form
```

The form model becomes the Single Source Of Truth.

---

# Real-Life Analogy

Imagine a school examination system.

Traditional Approach:

```text
Teacher Manually Checks Forms
```

Reactive Approach:

```text
Central Examination System
            ↓
Controls Everything
```

Similarly:

```text
Reactive Forms
       ↓
Centralized Form Management
```

---

# Why

Template-Driven Forms work well for:

```text
Simple Forms

Small Applications
```

Enterprise applications require:

```text
Complex Validation

Dynamic Controls

Large Forms

Scalability

Testability
```

Reactive Forms solve these problems.

# FormControl

## What

Represents a single form field.

---

## Lab 1: First FormControl

### Component

```typescript
import {

FormControl

}
from '@angular/forms';

```

---

## Template

```html
<input

[type]="text"

[formControl]="name">

<h2>

</h2>
```

```text
Real-Time Input Tracking
```

# FormGroup

## What

Groups multiple FormControls.

---

## Lab 2: First FormGroup

### Component

```typescript
import {

FormGroup,

FormControl

}
from '@angular/forms';

userForm =

new FormGroup({

name:

new FormControl(''),

email:

new FormControl('')

});
```

---

## Template

```html
<form

[formGroup]="userForm">

<input

formControlName="name">

<input

formControlName="email">

</form>
```
