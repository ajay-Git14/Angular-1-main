# Technology: Angular

# Module 4: Forms

# Topic 2: User Input

## Goal

Understand User Input in Angular, learn how applications capture user data, and work with different input controls used in enterprise applications.

---

# What

User Input is the information entered by users into an application.

Examples:

```text
Name

Email

Mobile Number

Password

Address

Complaint Details

Feedback
```

Angular captures this information through form controls.

---

# Real-Life Analogy

Imagine a receptionist at a hospital.

Patient provides:

```text
Name

Age

Address

Symptoms
```

Receptionist records the information.

Similarly:

```text
User
   ↓
Input Control
   ↓
Angular
   ↓
Application
```

---

# Why

Without User Input:

```text
No Registration

No Login

No Transactions

No Data Collection
```

---

With User Input:

```text
Collect Information

Process Requests

Validate Data

Store Records
```
