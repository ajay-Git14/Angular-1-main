# Topic 5: Form Validation

## Goal

Understand Form Validation in Angular, learn how to validate user input, display meaningful validation messages, and implement enterprise-grade validation strategies.

---

# What

Validation ensures that users enter correct and meaningful information before submitting a form.

Without Validation:

```text
User
  ↓
Invalid Data
  ↓
Database
```

Problems:

```text
Empty Values

Incorrect Email

Invalid Phone Numbers

Bad Data Quality
```

---

With Validation:

```text
User
   ↓
Validation
   ↓
Valid Data
   ↓
Application
```

---

# Real-Life Analogy

Imagine airport security.

Passenger arrives:

```text
Passport Check

Identity Check

Ticket Check
```

Only valid passengers proceed.

Similarly:

```text
User Input
      ↓
Validation
      ↓
Accepted Data
```

## Why?

```text

```

---

## Lab 17: Create Validator

```typescript
import {

AbstractControl

}
from '@angular/forms';

export function
flatNumberValidator(

control:
AbstractControl

){

const value =
control.value;

if(

value &&
!value.startsWith('A')

){

return {

invalidFlat:true

};

}

return null;

}
```

---

## Apply Validator

```typescript

'',

]
```

# Cross Field Validation

## What?

Validate multiple fields together.

Example:

```text
Password

Confirm Password
```

Both must match.

---

## Lab 18

```typescript
passwordMatchValidator(
group:any
){

const password =

group.get(
'password'
)?.value;

const confirmPassword =

group.get(
'confirmPassword'
)?.value;

return password ===
confirmPassword

?

null

:

{
 passwordMismatch:true
};

}
```

---

## Apply

```typescript
this.fb.group(

{

password:[''],

confirmPassword:['']

},

{

validators:
passwordMatchValidator

}

);
```
