# Technology: Angular

# Module 4: Forms

# Topic 3: Template-Driven Forms

## Goal

Understand Template-Driven Forms in Angular, learn how Angular automatically creates and manages forms using templates, and build real-world form-based applications.

---

# What

Template-Driven Forms are Angular forms where most of the form logic is defined in the HTML template.

Angular automatically:

```text
Creates Form Model

Tracks Form State

Tracks Validation

Tracks User Input
```

Developer focuses mainly on:

```text
Template

Validation

Submission
```

---

# Real-Life Analogy

Imagine an online survey form.

You create:

```text
Questions

Input Fields

Submit Button
```

The survey system automatically:

```text
Tracks Answers

Tracks Required Questions

Checks Completion
```

Template-Driven Forms work similarly.

---

# Why

Without Template-Driven Forms:

```text
Manual Input Tracking

Manual Validation

More Code
```

With Template-Driven Forms:

```text
Less Code

Automatic Tracking

Built-In Validation

Fast Development
```

---

# Wrap-Up

## Key Takeaways

```text
Template-Driven Forms use FormsModule.

ngForm tracks entire form.

Angular automatically manages state.

Angular automatically manages validation.

Template-Driven Forms are suitable for small to medium forms.
```
