# Topic 3: File Upload

## Goal

Understand File Upload in Angular, learn how to upload files to a server, validate files, track upload progress, and build enterprise applications that support document, image, and media uploads.

---

## What

File Upload allows users to send files from their devices to a server.

Examples:

```text
Images

PDF Documents

Excel Files

Videos

Profile Pictures

Attachments
```

---

## Real-Life Analogy

Imagine submitting documents at a government office.

```text
User
 ↓
Select Document
 ↓
Submit
 ↓
Verification
 ↓
Storage
```

Similarly:

```text
User
 ↓
Select File
 ↓
Upload
 ↓
Server
 ↓
Database / Storage
```

---

With File Upload:
