# Topic 1: Error Handling

## Goal

Understand Error Handling in Angular, learn how to handle runtime errors, HTTP errors, and unexpected failures, and build enterprise applications that provide reliable and user-friendly experiences.

---

## What

Error Handling is the process of detecting, managing, and responding to errors without crashing the application.

Without Error Handling:

```text
User Action
      ↓
Error Occurs
      ↓
Application Crashes
```

---

With Error Handling:

```text
User Action
      ↓
Error Occurs
      ↓
Error Captured
      ↓
User-Friendly Message
      ↓
Application Continues
```

---

## Real-Life Analogy

Imagine a power outage in a shopping mall.

Without backup:

```text
Power Failure
      ↓
Mall Shutdown
```

---

With backup systems:

```text
Power Failure
      ↓
Generator Starts
      ↓
Mall Continues Working
```

Similarly:

```text
Application Error
       ↓
Error Handler
       ↓
Graceful Recovery
```

---

# Global Error Handling

## Why?

Instead of handling errors everywhere.

Use one centralized handler.

---

### Lab 9: Create Global Error Handler

```bash

global-error-handler
```

---

### Lab 10

```typescript

ErrorHandler

}
from '@angular/core';
```

---

```typescript
export class
GlobalErrorHandler

implements ErrorHandler{

handleError(
error:any
){

error
);

}

}
```
