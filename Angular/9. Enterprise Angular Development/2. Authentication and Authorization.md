# Topic 2: Authentication and Authorization

## Goal

Understand Authentication and Authorization in Angular, learn how users log in securely, how permissions are managed, and how enterprise applications protect sensitive features and data.

---

## What

Authentication and Authorization are two different security concepts.

### Authentication

```text
Who Are You?
```

Example:

```text
Username

Password

OTP

Biometric
```

---

### Authorization

```text
What Are You Allowed To Do?
```

Example:

```text
Resident

Admin

Manager

Super Admin
```

---

## Real-Life Analogy

Airport Security:

### Authentication

```text
Show Passport
      ↓
Verify Identity
```

---

### Authorization

```text
Economy Ticket
      ↓
Economy Lounge Only

Business Ticket
      ↓
Business Lounge Access
```

---

Similarly:

```text
Authentication
       ↓
Identity Verification

Authorization
       ↓
Permission Verification
```

---

## Why

Without Authentication:

```text
Anyone Can Login

Anyone Can Access Data

Security Risk
```

---

Without Authorization:

```text
Normal User Can Access Admin Pages

Permission Violations
```

---

With Both:

```text
Secure Access

Role-Based Access

Enterprise Security
```

---

# Auth Guard Example

### Lab 9

```typescript
export const authGuard = () => {

const token =

localStorage.getItem(
'token'
);

return !!token;

};
```

---

Output:

```text
Only Logged-In Users Allowed
```

---

# HTTP Interceptor For Token

## Why?

Attach token automatically.

---

# Authentication vs Authorization

| Authentication    | Authorization     |
| ----------------- | ----------------- |
| Who Are You?      | What Can You Do?  |
| Login             | Permissions       |
| Identity          | Access Rights     |
| User Verification | Role Verification |
| First Step        | Second Step       |
