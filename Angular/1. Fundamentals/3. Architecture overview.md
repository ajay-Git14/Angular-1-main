# Topic 6: Angular Folder Structure and Project Architecture

## Goal

Understand the complete Angular project structure, the purpose of every important file and folder, and how an Angular application flows from startup to browser rendering.

---

# What

When Angular CLI creates a project:

```bash
ng new society-portal
```

Angular automatically generates:

```text
society-portal/
├── .angular/
├── .vscode/
├── node_modules/
├── public/
├── src/
│
├── angular.json
├── package.json
├── package-lock.json
├── tsconfig.json
├── tsconfig.app.json
├── tsconfig.spec.json
└── README.md
```

Every folder has a purpose.

Understanding this structure is essential because enterprise Angular applications may contain:

```text
100+
Components

50+
Services

20+
Modules

Thousands Of Files
```

## Guided practical — Topic 03: Trace the application startup

**Goal:** Explain where an Angular application begins and identify the generated files without guessing their names.

1. From your workspace root, run `ng version` and open `angular.json`, `package.json`, `src/index.html`, and `src/main.ts` in VS Code.
2. In `src/main.ts`, locate the bootstrap call (typically `bootstrapApplication(...)`). Follow the imported root component to its TypeScript file.
3. Find `@Component({ ... })`; locate `selector`, `templateUrl` (or inline template), and `styleUrl`/`styleUrls` where present.
4. Follow `templateUrl` to the actual HTML file and add:

```html
<h1>Angular startup journey</h1>
<p>index.html → main.ts → root component → template</p>
```

5. Use `ng serve --open`. Draw the path you just followed:

```text
Browser loads index.html
  → Angular bootstrap in main.ts
  → Root component selected
  → Template rendered into the page
```

**Expected result:** A browser heading appears and you can point to the real filenames involved. The CLI terminal reports the development server URL.

**Important correction:** Files such as `angular.json` and `package.json` are **workspace-root files**, not children of `src/`. `index.html` is commonly under `src/`. Generated component names differ by Angular CLI version; always follow the imports and decorator.

**Memory hook:** *Entry → Bootstrap → Component → View.*

**Troubleshooting:** If your HTML doesn't change, confirm you edited the file named by the component decorator rather than a similarly named unused file.

**Practice:** Produce a table in your notes with columns **File**, **Purpose**, **Can I edit it?** for `package.json`, `angular.json`, `src/main.ts`, your root component TypeScript, and its template.

Reference: https://angular.dev/guide/components
