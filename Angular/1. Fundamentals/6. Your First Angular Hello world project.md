> **Version note:** New Angular CLI projects may generate `app.ts`, `app.html` and class `App`, while older releases may use `app.component.ts`, `app.component.html` and `AppComponent`. **Do not replace the generated component decorator or class name with an incomplete snippet.** Add the lesson's properties *inside your existing generated component class*. Choose the file referenced by `templateUrl`. Follow the Angular CLI prompts in your own installed version.

## Guided practical — Topic 06: Build, break, and fix Hello World

**Goal:** Complete a tiny Angular screen with visible feedback and learn how to recover from an everyday mistake.

1. Follow the [Module 01 beginner practical](./00.%20START%20HERE%20-%20Hands-on%20Beginner%20Lab.md) using the workspace you created.
2. Keep the generated `@Component` metadata, class declaration, and existing imports. Inside that class add:

```ts
title = 'My Society Portal';
clicks = 0;
increment() {
  this.clicks += 1;
}
```

3. Open the HTML file referenced by `templateUrl`. Replace the existing welcome markup with:

```html
<main>
  <h1>{{ title }}</h1>
  <p>Button clicks: {{ clicks }}</p>
  <button type="button" (click)="increment()">Report a click</button>
</main>
```

4. In the component stylesheet referenced by `styleUrl` or `styleUrls`, enter:

```css
main { max-width: 36rem; margin: 3rem auto; font-family: system-ui, sans-serif; }
button { padding: .6rem 1rem; cursor: pointer; }
```

5. Start `ng serve --open`. Click the button three times.

**Expected result:** Title 'My Society Portal' appears and count changes from 0 to 3. Refreshing resets the count: it was only stored in memory.

**Debugging exercise:** Temporarily change `(click)="increment()"` to `(click)="incrementWrong()"`. Observe the compiler's missing-property error, then restore the correct method name. This teaches you to read the file/line information, not guess.

**Memory hook:** *Change class state → binding refreshes view.*

**Troubleshooting:** If the stylesheet is not applied, check the exact component stylesheet path in the decorator. If the root component has an inline template, modify that property instead of creating an unused HTML file.

**Challenge:** Replace 'My Society Portal' with your own project title; add a second button that resets `clicks = 0`.

**Instructor check:** Learner can run the app, explain the binding and event, and recover from the deliberate compiler error.

Reference: https://angular.dev/tutorials/first-app
