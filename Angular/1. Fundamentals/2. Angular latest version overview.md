## Lab 5: Signal Introduction

### What

Signals provide reactive state management.

```typescript
import {
    signal
} from '@angular/core';

const count =
    signal(0);
```

Read:

```typescript
count();
```

Update:

```typescript
count.set(1);
```

---

## Lab 6: Signal Example

## Guided practical — Topic 02: Identify modern Angular features yourself

**Goal:** Confirm your installed Angular version and use a signal plus built-in control flow instead of memorizing a possibly outdated 'latest version' number.

1. In your workspace run `ng version`. Record the **Angular CLI** and **Angular** versions shown. Compare the supported Node/TypeScript combinations with https://angular.dev/reference/versions.
2. Open the root component TypeScript file indicated by its `@Component` decorator. Add `signal` to the existing `@angular/core` import (do not duplicate imports). Inside the existing component class add:

```ts
count = signal(0);
items = ['Components', 'Signals', 'Templates'];
increase() {
  this.count.update(value => value + 1);
}
```

3. In the root HTML template, put:

```html
<h1>Modern Angular feature check</h1>
<button (click)="increase()">Count: {{ count() }}</button>
@if (count() > 0) {
  <p>You changed reactive state.</p>
}
<ul>
  @for (item of items; track item) {
    <li>{{ item }}</li>
  }
</ul>
```

4. Run `ng serve --open`, click twice, and watch the condition change.

**Expected result:** Counter reads 0, 1, 2; explanation appears after the first click; three feature names remain visible.

**Concept checkpoints:** `signal(0)` stores reactive state; `count()` reads it; `update` changes it; `@if` conditionally renders; `@for` repeats items. **Memory hook:** *Signal stores; template reads; event updates.*

**Troubleshooting:** If `signal` is not imported, TypeScript cannot find it. If `@if` or `@for` is unrecognized, check Angular version and official guide before changing syntax.

**Practice:** Add a Reset button using `count.set(0)` and a fourth list item.

**Version caution:** This chapter is conceptual; 'latest' changes. Confirm current documentation rather than treating a historical version mentioned in earlier examples as a live fact.

References: https://angular.dev/guide/signals and https://angular.dev/guide/templates/control-flow
