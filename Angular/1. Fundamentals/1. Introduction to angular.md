# How It Works

## Traditional Website

```text
User Requests Page
        ↓
Server Generates HTML
        ↓
Browser Loads Page
        ↓
Every Click Reloads Page
```

---

## Angular Application

```text
User Opens Application
        ↓
Angular Loads Once
        ↓
User Navigates
        ↓
Only Required Data Updates
        ↓
No Full Page Reload
```

## Guided practical — Topic 01: Observe Angular in the browser

**Goal:** Recognize the three responsibilities: HTML describes content, CSS styles it, and TypeScript provides behavior. No programming experience beyond opening a terminal is assumed.

**Before starting:** Complete [the module setup workbook](./00.%20START%20HERE%20-%20Hands-on%20Beginner%20Lab.md). Open the generated `angular-confidence-labs` workspace in VS Code.

1. Locate your root component's HTML template from its `templateUrl` (often `src/app/app.html`). Replace its contents with:

```html
<h1>Society Help Desk</h1>
<p>Residents can report issues here.</p>
<button (click)="showMessage()">What is Angular doing?</button>
<p>{{ explanation }}</p>
```

2. Open its matching TypeScript file (often `src/app/app.ts`). Inside the **existing exported component class**, add:

```ts
explanation = 'Click the button to find out.';
showMessage() {
  this.explanation = 'Angular connected a browser click to TypeScript data!';
}
```

3. Save both files, run `ng serve --open` in the workspace root, and click the button.

**Expected result:** The browser shows the Society Help Desk heading, then changes the explanation on click without a page reload.

**Why it works:** HTML is the template, the class owns the data and method, and Angular binds `(click)` to the method and `{{ explanation }}` to the displayed text. **Memory hook:** *Template = screen; class = brain; binding = wire.*

**If it fails:** A 'Property ... does not exist' error means the name in the HTML does not exactly match the class member. An 'ng not recognized' error means the CLI is unavailable on your terminal PATH.

**Try alone:** Change the heading and add a second paragraph. Write down which edits belong in HTML versus TypeScript.

**Evidence:** Capture the screen before and after your button click; explain the three responsibilities in one minute.

Reference: https://angular.dev/guide/components
