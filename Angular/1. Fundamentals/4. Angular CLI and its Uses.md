# Topic 4: Angular CLI Commands
## Goal

Understand the most important Angular CLI commands used daily by Angular developers to create, run, generate, build, test, and maintain Angular applications.

---

# What

Angular CLI Commands are predefined commands provided by Angular CLI to automate development tasks.

Without CLI:

```text
Create Files Manually

Create Folders Manually

Configure TypeScript Manually

Configure Angular Manually
```

---

With CLI:

```text
Single Command

Everything Generated Automatically
```

---

## Real-Life Analogy

Imagine a washing machine.

Without machine:

```text
Wash Clothes Manually

Dry Manually

Spend Hours
```

With machine:

```text
Press Button

Machine Does Work
```

Angular CLI works similarly.

---

# Why

Enterprise Angular applications may contain:

```text
200+ Components

100+ Services

50+ Models

20+ Guards

10+ Directives
```

Creating everything manually becomes inefficient.

Angular CLI automates:

```text
Creation

Configuration

Compilation

Testing

Building
```

---

# How It Works

```text
Developer
      ↓
CLI Command
      ↓

      ↓
Files Generated
      ↓
Application Ready
```

## Guided practical — Topic 04: Use Angular CLI without fear

**Goal:** Generate a component and understand what each command does.

**Prerequisite:** Work inside `angular-confidence-labs` (the folder containing `angular.json`).

1. Open VS Code Terminal. Run `ng help`, then `ng generate --help`. These explain commands without changing code.
2. Run `ng generate component help-card`. Read the terminal list of created files.
3. Open the new component's HTML file under `src/app/help-card/` and replace its contents:

```html
<section>
  <h2>Need help?</h2>
  <p>Our society team can guide you.</p>
</section>
```

4. Open the root component TypeScript. Import the actual generated `HelpCard` class and add it to the root component's `imports` array. For projects using a different generated name (e.g. `HelpCardComponent`), use that export.
5. In root HTML add `<app-help-card></app-help-card>`. If your generated selector differs, use the selector printed in the child's `@Component`.
6. Run `ng serve --open` and confirm the card appears. Stop the server with Ctrl+C.

**Expected result:** New component files exist, no import errors occur, and the browser displays 'Need help?'.

**Memory hook:** *Generate = create files; Serve = preview; Build = package.*

**Troubleshooting:** 'Unknown element' usually means the root component did not import the new standalone component. 'Outside a workspace' means the terminal is not inside the folder containing `angular.json`.

**Practice:** Run `ng generate component contact-card`, render it, and describe the generated files. Run `ng build` only after the app is free of errors.

Reference: https://angular.dev/tools/cli
