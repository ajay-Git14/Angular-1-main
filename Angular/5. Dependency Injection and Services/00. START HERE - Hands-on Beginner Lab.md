# Beginner Practical Lab — Student Workbook

> **Audience:** First-time Angular learners. **Goal:** Finish with a visible, working result rather than only reading theory.

## How to use this lab
1. Read the **Goal** and **Before you start** sections.
2. Type the commands yourself in **VS Code > Terminal > New Terminal** (do not type the dollar sign if shown in examples).
3. Copy each code block into the **exact filename** indicated. Save with **Ctrl+S**.
4. Keep `ng serve` running in one terminal. Use a second terminal for commands.
5. Check the **Expected result** after every small change. If it differs, use **Troubleshooting** before moving on.

## One-time workstation setup (complete once; reuse in every module)
- Install a Node.js **LTS release compatible with your chosen Angular release**: https://nodejs.org/
- Install Visual Studio Code: https://code.visualstudio.com/
- In VS Code, install **Angular Language Service** and **ESLint** extensions (ESLint requires project configuration).
- Run `node --version` and `npm --version`. Both should print versions.
- Install CLI: `npm install -g @angular/cli`; verify with `ng version`.
- Create a workspace once: `ng new angular-confidence-labs --routing --style=css --skip-tests=false` (accept the default standalone setup when offered).
- Open it: `cd angular-confidence-labs` then `code .`.
- Start: `ng serve --open`; expected URL: **http://localhost:4200/**.
- Angular CLI prompts, filenames and generated test runner can vary by CLI version. Use the generated files in your project rather than guessing.

**Check your CLI and Angular version against:** https://angular.dev/reference/versions and https://angular.dev/tools/cli/setup-local . Do not assume every historical Angular tutorial uses the current syntax.

# Module 05: Share logic through an injectable service

## Goal
Keep calculations in a service instead of inside a UI component.

## Steps
1. Run `ng generate service price`.
2. Open the generated service TypeScript file. Keep `@Injectable({ providedIn: 'root' })` and add the following method inside the service class:

```ts
finalPrice(amount: number, discountPercent: number): number {
  if (amount < 0 || discountPercent < 0 || discountPercent > 100) {
    throw new Error('Enter a positive amount and discount from 0 to 100.');
  }
  return amount * (1 - discountPercent / 100);
}
```

3. In a generated component, import `inject` from `@angular/core` and your generated service class using its actual filename.
4. Inside that component class, add:

```ts
private priceService = inject(PriceService);
discounted = this.priceService.finalPrice(1000, 10);
```

5. Replace its template with `<p>Discounted amount: {{ discounted }}</p>` and display it from the root component.

## Expected result
The browser displays **Discounted amount: 900**.

## Why this works
`providedIn: 'root'` registers a service for dependency injection. `inject(PriceService)` asks Angular for that service rather than manually creating it.

## Troubleshooting
- **PriceService is not found:** verify the actual generated exported class name and import path.
- **No injection context:** call `inject()` in a class field initializer or constructor, not inside an unrelated click handler.
- **Blank page:** open browser DevTools Console and inspect errors.
