# Topic 1: Routing & Navigation

## Goal

Understand Angular Routing, learn how navigation works in Single Page Applications (SPA), and build enterprise applications with multiple screens and seamless navigation.

---

# What

Routing is the mechanism that allows users to move between different pages or screens in an Angular application.

Without Routing:

```text
Application
     ↓
Single Screen Only
```

With Routing:

```text
Home
 ↓
Login
 ↓
Dashboard
 ↓
Reports
 ↓
Settings
```

---

# Real-Life Analogy

Imagine a shopping mall.

```text
Main Entrance
      ↓
Electronics
      ↓
Food Court
      ↓
Clothing
      ↓
Cinema
```

People navigate between sections.

Similarly:

```text
User
  ↓
Angular Router
  ↓
Different Screens
```

---

# Why

Without Routing:

```text
One Huge Component

Poor Maintainability

No Navigation Experience
```

---

With Routing:

```text
Multiple Screens

Better User Experience

Clean Architecture

Scalable Applications
```

# Single Page Application (SPA)

Angular is a SPA framework.

Traditional Website:

```text
Click Link
    ↓
Server Returns New Page
```

Angular SPA:

```text
Click Link
    ↓
Angular Changes Component
    ↓
No Full Page Refresh
```
