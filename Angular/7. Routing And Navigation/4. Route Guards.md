# Technology: Angular

# Module 7: Routing and Navigation

# Topic 4: Route Guards

## Goal

Understand Route Guards in Angular, learn how to protect routes, control user access, and implement enterprise-grade authentication and authorization.

---

# What

Route Guards are Angular mechanisms that decide whether a user can access a route.

Without Route Guards:

```text
User
 ↓
Any Screen
 ↓
Access Granted
```

---

With Route Guards:

```text
User
 ↓
Route Guard
 ↓
Validation
 ↓
Allow / Deny Access
```

---

# Real-Life Analogy

Imagine a company's office building.

```text
Employee
      ↓
Security Check
      ↓
Valid ID?
      ↓
Access Granted
```

Unauthorized person:

```text
Visitor
     ↓
Security Check
     ↓
No Access
```

Angular Route Guards work similarly.

---

# Why

Without Guards:

```text
Anyone Can Access Dashboard

Anyone Can Access Reports

```

With Guards:

```text
Protected Routes

Role-Based Navigation
```

## What

Determines whether route can be activated.

---

## Lab 2: First Guard

```typescript
import {

CanActivateFn

}
from '@angular/router';

export const authGuard:

CanActivateFn = () => {

};
```

# Redirect User

## Lab 5

```typescript
export const authGuard:

CanActivateFn = () => {

const router =
inject(Router);

const loggedIn =
false;

if(!loggedIn){

router.navigate(
['/login']
);

return false;

}

return true;

};
```

---

Output:

```text
Redirect To Login
```
