# Technology: Angular

# Module 7: Routing and Navigation

# Topic 2: Route Parameters

## Goal

Understand Route Parameters in Angular, learn how to pass data through URLs, retrieve values from URLs, and build enterprise applications with dynamic navigation.

---

# What

Route Parameters allow Angular applications to pass data through URLs.

Example:

```text
/employee/101

101 = Employee ID
```

Another example:

```text
/complaint/5001

5001 = Complaint ID
```

Angular reads these values and displays the appropriate data.

---

# Real-Life Analogy

Imagine a courier tracking website.

```text
https://tracking.com/TRK12345
```

TRK12345 identifies a specific package.

Similarly:

```text
/employee/101
```

101 identifies a specific employee.

---

# Why

Without Route Parameters:

```text
Cannot Open Specific Records

Cannot View Individual Data

No Dynamic Navigation
```

---

With Route Parameters:

```text
Open Specific Records

Dynamic URLs

Bookmarkable Pages

SEO Friendly URLs
```

---

# How It Works

```text
User Opens URL
       ↓
Angular Router
       ↓
Reads Parameter
       ↓
Loads Data
       ↓
Displays Screen
```

# Observable Route Parameters

## Why?

Snapshot reads only once.

Observable updates automatically.

---

## Lab 13

```typescript
this.route
.paramMap
.subscribe(

params => {

this.employeeId =

params.get('id');

}

);
```

---

Output:

```text
Automatically Updates
```

---

# Query Parameters

## What?

Additional URL information.

---
