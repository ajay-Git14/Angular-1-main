# Topic 1: Angular Build

## Goal

Understand the Angular Build process, learn how Angular converts source code into deployable production bundles, and build enterprise-ready Angular applications for deployment.

---

## What

Angular Build is the process of converting Angular source code into optimized files that browsers can execute.

Before Build:

```text
TypeScript

HTML

SCSS

Angular Components

Services

Routes
```

---

After Build:

```text
JavaScript

CSS

HTML

Assets

Optimized Bundles
```

---
