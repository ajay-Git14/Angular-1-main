## Goal

Understand what JavaScript is, why it exists, how it works, where it is used, and why it is the foundation of TypeScript and Angular development.

---

# What

JavaScript is a programming language that makes web pages interactive and dynamic.

Without JavaScript:

```text
Web pages can only display information.
```

With JavaScript:

```text
Web pages can respond to users.
```

Examples:

* Login validation
* Search functionality
* Shopping cart updates
* Form submission
* Real-time notifications
* API communication

JavaScript is one of the most widely used programming languages in the world.

Today it is used in:

* Frontend Development
* Backend Development
* Mobile Applications
* Desktop Applications
* Cloud Applications
* AI Applications

---

# Why

Imagine a restaurant.

```text
Menu Card = HTML
Decoration = CSS
Waiter + Kitchen Operations = JavaScript
```

Without the waiter:

```text
Customer can see menu.
Customer cannot place order.
```

Without JavaScript:

```text
User can see website.
User cannot interact effectively.
```

With JavaScript:

```text
User clicks button.
Application responds.
Data changes.
Screen updates.
```

---

## Why Angular Developers Must Learn JavaScript

Angular is not a separate language.

Angular is built on:

```text
JavaScript
      ↓
TypeScript
      ↓
Angular
```

If JavaScript is weak:

```text
TypeScript becomes difficult.
Angular becomes difficult.
Debugging becomes difficult.
```

# How It Works

## Browser View

```text
Browser
│
├── HTML Engine
│
├── CSS Engine
│
└── JavaScript Engine
```

Examples:

| Browser | Engine         |
| ------- | -------------- |
| Chrome  | V8             |
| Edge    | V8             |
| Firefox | SpiderMonkey   |
| Safari  | JavaScriptCore |

---

## Execution Flow

```text
User Action
      ↓
JavaScript Executes
      ↓
Browser Updates Screen
```

Example:

```text
Click Login
      ↓
Validate Input
      ↓
Show Success Message
```
