## Goal

Understand what Callbacks are, why JavaScript needs Callbacks, how asynchronous operations work, and how Callbacks are used in real-world applications and Angular development.

---

# What

A Callback is a function passed as an argument to another function and executed later when a specific task is completed.

In simple words:

```text
A function that is called back later.
```

---

## Simple Example

```javascript
function greet(name) {
    console.log("Hello " + name);
}

function processUser(callback) {
    callback("Deepak");
}

processUser(greet);
```

Output:

```text
Hello Deepak
```

---

# Why

Imagine ordering food in a restaurant.

Without Callback:

```text
Place Order
Wait At Counter
Do Nothing Else
```

With Callback:

```text
Place Order
Sit At Table
Continue Talking
Food Ready
Waiter Calls You
```

Callback is similar.

```text
Start Task
Continue Other Work
Task Completes
Callback Executes
```

---

## Why JavaScript Needs Callbacks

JavaScript is single-threaded.

```text
One Task At A Time
```

Many operations take time:

* API Calls
* Database Calls
* File Reading
* User Clicks
* Timer Operations

Callbacks allow JavaScript to continue working while waiting.

---

# How It Works

## Synchronous Execution

```text
Task 1
 ↓
Task 2
 ↓
Task 3
```

Everything waits.

---

## Asynchronous Execution

```text
Start Long Task
        ↓
Continue Other Work
        ↓
Task Completes
        ↓
Callback Executes
```

---

## Example

```javascript
console.log("Start");

setTimeout(function() {
    console.log("Callback Executed");
}, 2000);

console.log("End");
```

Output:

```text
Start
End
Callback Executed
```

# Core Concepts Overview

## Callback Function

Function passed to another function.

```javascript
function greet() {
}
```

---

## Higher Order Function

Function accepting another function.

```javascript
function process(callback) {
}
```

---

## Asynchronous Task

Task that takes time.

Examples:

```text
API Call
Database Query
File Read
Timer
```

---

## Event Callback

Triggered when user performs action.

Examples:

```text
Click
Submit
Change
Hover
```

# Hands-On Labs

## Lab 1: Basic Callback

```javascript
function displayMessage(callback) {
    callback();
}

function sayHello() {
    console.log("Hello JavaScript");
}

displayMessage(sayHello);
```

Output:

```text
Hello JavaScript
```

---

## Lab 2: Callback With Parameters

```javascript
function processStudent(callback) {
    callback("Deepak");
}

function displayStudent(name) {
    console.log("Student: " + name);
}

processStudent(displayStudent);
```

Output:

```text
Student: Deepak
```

---

## Lab 3: Calculation Callback

```javascript
function calculate(a, b, callback) {
    callback(a, b);
}

function add(x, y) {
    console.log(x + y);
}

calculate(10, 20, add);
```

Output:

```text
30
```

---

## Lab 4: Simulating API Response

```javascript
function fetchData(callback) {

    console.log("Loading Data...");

    setTimeout(function() {
        callback("Angular Course Loaded");
    }, 2000);
}

fetchData(function(result) {
    console.log(result);
});
```

Output:

```text
Loading Data...
Angular Course Loaded
```

---

## Lab 5: Event Callback

```javascript
document.addEventListener("click", function() {
    console.log("User Clicked");
});
```

Concept:

```text
User Click
      ↓
Browser Detects Event
      ↓
Callback Executes
```

---

## Lab 6: Trainer Selection Example

```javascript
function shortlistTrainer(callback) {

    let trainer =
        "Deepak";

    callback(trainer);
}

shortlistTrainer(function(name) {

    console.log(
        "Selected Trainer: "
        + name
    );

});
```

Output:

```text
Selected Trainer: Deepak
```

---

## Lab 7: Angular API Style Simulation

```javascript
function loadCourses(callback) {

    setTimeout(function() {

        callback([
            "JavaScript",
            "TypeScript",
            "Angular"
        ]);

    }, 1000);
}

loadCourses(function(courses) {

    console.log(courses);

});
```

Output:

```text
JavaScript
TypeScript
Angular
```

# Wrap-Up

## Key Takeaways

```text
Callbacks are functions.

Callbacks can be passed to other functions.

Callbacks execute later.

Callbacks enable asynchronous programming.

Callbacks are heavily used in events and API operations.
```
