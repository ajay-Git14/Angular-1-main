## Goal

Understand what Prototype Inheritance is, why JavaScript uses prototypes, how objects inherit properties and methods, and how prototype-based inheritance differs from class-based inheritance.

---

# What

Prototype Inheritance is the mechanism through which one JavaScript object can access properties and methods from another object.

In simple words:

```text
An object can borrow functionality
from another object.
```

JavaScript does not use traditional class inheritance internally.

Instead, JavaScript uses:

```text
Object
     ↓
Prototype
     ↓
Inherited Properties
     ↓
Inherited Methods
```

---

## Example

```javascript
let trainer = {
    technology: "Angular",

    teach() {
        console.log("Teaching Angular");
    }
};

let employee = Object.create(trainer);

console.log(employee.technology);

employee.teach();
```

Output:

```text
Angular
Teaching Angular
```

---

# Why

Imagine a company.

Without inheritance:

```text
Trainer has ID Card

Developer has ID Card

Manager has ID Card

Tester has ID Card
```

Every employee repeats the same information.

---

With inheritance:

```text
Employee
     ↓
Trainer
Developer
Manager
Tester
```

Common functionality is shared.

Benefits:

```text
Code Reuse

Less Duplication

Better Maintenance

Shared Functionality
```

```text
Object
```

```text
Child Object

Parent Object
```

JavaScript keeps checking parent objects until property is found.

```text
Object
   ↓
Prototype
   ↓
```

```javascript
    companyName: "TechLambda"
```

## Lab 6: Constructor Function Prototype

```javascript
function Trainer(name) {

    this.name = name;

}

Trainer.prototype.teach =
    function() {

        console.log(
            this.name +
            " teaching Angular"
        );

    };

let trainer1 =
    new Trainer("Deepak");

trainer1.teach();
```

Output:

```text
Deepak teaching Angular
```

## Lab 7: Angular Team Example

```javascript
function Employee(name) {

emp1.work();
```

```text
Deepak working
```
