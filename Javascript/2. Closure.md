## Goal

Understand what a Closure is, why JavaScript needs Closures, how Closures work internally, and how they are used in real-world Angular and JavaScript applications.

---

# What

A Closure is a JavaScript feature where a function remembers and can access variables from its outer scope even after the outer function has finished execution.

In simple words:

```text
A Closure remembers its surrounding environment.
```

---

## Example

```javascript
function outer() {

    let trainerName = "Deepak";

    function inner() {
        console.log(trainerName);
    }

    return inner;
}

let result = outer();

result();
```

Output:

```text
Deepak
```

Question:

```text
outer() execution already finished.

Then how did inner() remember trainerName?
```

Answer:

```text
Because of Closure.
```

---

# Why

Without Closures:

```text
Function loses access to outer variables
Private data becomes difficult
State tracking becomes difficult
Callbacks become difficult
```

With Closures:

```text
Function remembers data
Private variables become possible
State management becomes easier
Reusable logic becomes possible
```

---

## Real-Life Analogy

Imagine a bank locker.

```text
Customer gets a locker
Customer leaves bank
Locker still contains belongings
Customer returns later
Locker data still exists
```

Closure behaves similarly.

```text
Function created
Outer function finishes
Inner function survives
Data still exists
```

# How It Works

## Normal Function Execution

```text
Function Starts
       ↓
Variables Created
       ↓
Function Ends
       ↓
Variables Removed
```

---

## Closure Execution

```text
Outer Function Starts
        ↓
Variable Created
        ↓
Inner Function Created
        ↓
Outer Function Ends
        ↓
Variable Kept Alive
        ↓
Inner Function Uses Variable
```

---

# Core Concepts Overview

## Outer Function

Creates data.

```javascript
function outer() {

}
```

---

## Inner Function

Uses outer data.

```javascript
function inner() {

}
```

---

## Closure

Combination of:

```text
Function
+
Remembered Variables
```

---

## Lexical Scope

JavaScript determines variable access based on where functions are written.

```text
Written Inside
      ↓
Can Access Parent Variables
```

Closures depend on lexical scope.

function outer() {

    return inner;

## Lab 2: Counter Example

### Objective

Remember state using Closure.

```javascript
function counter() {

    let count = 0;

    return function() {

        count++;

        console.log(count);
    };
}

let increment = counter();

increment();
increment();
increment();
```

### Output

```text
1
2
3
```

---

## Lab 3: Private Variable

### Objective

Hide data from outside world.

```javascript
function bankAccount() {

    let balance = 1000;

    return function() {
        console.log(balance);
    };
}

let checkBalance = bankAccount();

checkBalance();
```

Output:

```text
1000
```

## Lab 4: Multiple Closures

```javascript
function trainer(name) {

    return function() {
        console.log("Trainer : " + name);
    };
}

let trainer1 = trainer("Deepak");
let trainer2 = trainer("Rahul");

trainer1();
trainer2();
```

Output:

```text
Trainer : Deepak
Trainer : Rahul
```

## Lab 6: Closure State Preservation

```javascript
function createStudentTracker() {

    let totalStudents = 0;

    return function() {

        totalStudents++;

        console.log(
            "Total Students : "
            + totalStudents
        );
    };
}

let addStudent =
    createStudentTracker();

addStudent();
addStudent();
addStudent();
```

Output:

```text
Total Students : 1
Total Students : 2
Total Students : 3
```
