## Goal

Understand how NPM is used to initialize, manage, build, and maintain modern JavaScript, TypeScript, Angular, React, Node.js, and enterprise projects.

---

# What

NPM (Node Package Manager) is the standard tool used to:

* Create projects
* Install dependencies
* Manage packages
* Run scripts
* Build applications
* Update libraries

Think of NPM as:

```text
Project Manager for JavaScript Ecosystem
```

Without NPM:

```text
Download libraries manually
Copy files manually
Manage versions manually
Run applications manually
```

With NPM:

```text
Single command creates project
Single command installs packages
Single command runs project
Single command builds project
```

---

# Why

## Real-Life Analogy

Imagine building a house.

Without NPM:

```text
Buy cement separately
Buy bricks separately
Buy steel separately
Track everything manually
```

With NPM:

```text
One supplier manages everything
```

Similarly:

```text
NPM manages all project dependencies.
```

---

## Why Angular Developers Need NPM

Angular depends heavily on NPM.

```text
Angular Project
      ↓
package.json
      ↓
NPM Packages
      ↓
Node Modules
      ↓
Application Runs
```

Without NPM:

```text
Angular CLI cannot work
Dependencies cannot be installed
Project cannot run
```

# How It Works

## Project Lifecycle

```text
Create Project
      ↓
Initialize package.json
      ↓
Install Packages
      ↓
Develop Application
      ↓
Run Scripts
      ↓
Build Application
      ↓
Deploy Application
```

# Core Concepts Overview

## package.json

Project configuration file.

Contains:

```text
Project Name
Version
Scripts
Dependencies
Author
License
```

---

## node_modules

Stores installed packages.

---

## Dependencies

Packages required by application.

Example:

```text
Angular
RxJS
Zone.js
```

---

## Dev Dependencies

Packages used only during development.

Example:

```text
TypeScript
Angular CLI
ESLint
```

---

## Scripts

Commands stored in package.json.

Example:

```json
"scripts": {
  "start": "node app.js"
}
```
