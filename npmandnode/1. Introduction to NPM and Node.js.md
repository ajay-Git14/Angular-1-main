# Introduction to NPM and Node.js

## Goal

Understand what Node.js and NPM are, why they were created, how JavaScript runs outside the browser, and why Angular development depends on Node.js and NPM.

---

# What

## What is Node.js?

Node.js is a JavaScript runtime environment that allows JavaScript to run outside the browser.

Before Node.js:

```text
JavaScript could run only inside browsers.
```

After Node.js:

```text
JavaScript can run on servers.
JavaScript can build APIs.
JavaScript can build backend applications.
JavaScript can automate tasks.
```

---

## What is NPM?

NPM stands for:

```text
Node Package Manager
```

NPM is used to:

* Install libraries
* Manage dependencies
* Run project commands
* Create projects
* Update packages

Think of NPM as:

```text
Google Play Store for JavaScript packages
```

---

# Why

## Real-Life Analogy

Imagine opening a restaurant.

Without Node.js:

```text
Customers can see menu.
Orders cannot be processed.
```

With Node.js:

```text
Customers place order.
Kitchen processes order.
Food is prepared.
```

---

## Angular Analogy

```text
JavaScript = Raw Material

Node.js = Factory

NPM = Warehouse

Angular = Final Product
```

Without Node.js:

```text
Angular cannot run.
Angular CLI cannot work.
NPM cannot install packages.
```

# Wrap-Up

## Key Takeaways

```text
Node.js allows JavaScript to run outside browser.

NPM manages JavaScript packages.

Angular depends on Node.js.

Angular depends on NPM.

Every Angular project uses package.json.

Node.js + NPM are mandatory for Angular development.
```
