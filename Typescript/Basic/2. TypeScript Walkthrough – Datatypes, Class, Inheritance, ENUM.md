## Lab 8: First Class

```typescript
class Trainer {

    name: string;

    technology: string;

    constructor(
        name: string,
        technology: string
    ) {

        this.name = name;

        this.technology =
            technology;
    }

    display() {

        console.log(
            this.name +
            " teaches " +
            this.technology
        );

    }

}

let trainer1 =
    new Trainer(
        "Deepak",
        "Angular"
    );

trainer1.display();
```

Output:

```text
Deepak teaches Angular
```

---

## Lab 9: Inheritance

### Parent Class

```typescript
class Employee {

    company: string =
        "TechLambda";

}
```

### Child Class

```typescript
class Trainer
    extends Employee {

    technology: string =
        "Angular";

}
```

### Usage

```typescript
let trainer1 =
    new Trainer();

console.log(
    trainer1.company
);

console.log(
    trainer1.technology
);
```

Output:

```text
TechLambda
Angular
```

---

## Lab 10: Multi-Level Inheritance

```typescript
class Person {

    name: string =
        "Deepak";

}

class Employee
    extends Person {

    company: string =
        "TechLambda";

}

class Trainer
    extends Employee {

    technology: string =
        "Angular";

}
```

Usage:

```typescript
let trainer1 =
    new Trainer();

console.log(trainer1.name);

console.log(trainer1.company);

console.log(
    trainer1.technology
);
```

Output:

```text
Deepak
TechLambda
Angular
```

## Lab 11: ENUM

### What

Enum stores fixed constant values.

Without Enum:

```typescript
let status =
    "Active";
```

Problem:

```text
Typing mistakes possible.
```

---

### Enum Example

```typescript
enum Status {

    Active,

    Inactive,

    Pending

}
```

Usage:

```typescript
let employeeStatus =
    Status.Active;

console.log(
    employeeStatus
);
```

Output:

```text
0
```

enum Role {

## Lab 13: Angular Model Example

```typescript
enum Department {

    IT = "IT",

    HR = "HR",

    Finance = "Finance"

}

class Employee {

    constructor(

        public id: number,

        public name: string,

        public department:
        Department

    ) {}

}

let emp1 =
    new Employee(

        101,

        "Deepak",

        Department.IT

    );

console.log(emp1);
```

This is very similar to Angular Model classes.
