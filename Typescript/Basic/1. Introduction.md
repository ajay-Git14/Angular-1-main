## Goal

Understand what TypeScript is, why it was created, how it extends JavaScript, and why Angular uses TypeScript as its primary development language.

---

# What

TypeScript is a programming language developed by Microsoft that builds on top of JavaScript.

In simple words:

```text
TypeScript = JavaScript + Type Safety + Extra Features
```

TypeScript does not replace JavaScript.

Instead:

```text
JavaScript
      +
Type Checking
      +
Modern Features
      =
TypeScript
```

---

## Example

### JavaScript

```javascript
let age = 25;

age = "Twenty Five";
```

No error.

---

### TypeScript

```typescript
let age: number = 25;

age = "Twenty Five";
```

Error:

```text
Type 'string' is not assignable to type 'number'
```

---

# Why

Imagine a hospital.

Without patient identification:

```text
Wrong patient
Wrong medicine
Wrong treatment
```

Problems occur.

---

With proper identification:

```text
Correct patient
Correct medicine
Correct treatment
```

Everything becomes safer.

---

TypeScript does the same.

Without TypeScript:

```text
Wrong Data Types
Runtime Errors
Debugging Problems
```

With TypeScript:

```text
Early Error Detection
Better Code Quality
Better Team Collaboration
Safer Development
```

---

## Why Angular Uses TypeScript

Angular applications are usually:

```text
Large
Enterprise Level
Multiple Developers
Long-Term Projects
```

TypeScript helps by providing:

```text
Type Safety
Interfaces
Classes
Decorators
Better Tooling
```

Angular is officially built around TypeScript.

---

# How It Works

## Development Flow

```text
TypeScript Code
        ↓
TypeScript Compiler (tsc)
        ↓
JavaScript Code
        ↓
Browser Executes
```

Important:

```text
Browsers do NOT understand TypeScript.

Browsers understand JavaScript.
```

Therefore:

```text
TypeScript
       ↓
Compile
       ↓
JavaScript
       ↓
Browser
```

## Lab 1: First TypeScript Program

### Create

```text
app.ts
```

### Code

```typescript
console.log(
    "Welcome To TypeScript"
);
```

---

### Compile

```bash
tsc app.ts
```

Generated:

```text
app.js
```

## Lab 3: Type Inference

```typescript
let technology =
    "Angular";
```

TypeScript automatically understands:

```text
technology = string
```

No need to write:

```typescript
let technology: string =
    "Angular";
```
