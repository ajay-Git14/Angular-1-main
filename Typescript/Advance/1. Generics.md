## Goal

Understand what Generics are, why they are important, how they improve code reusability and type safety, and how Angular applications use Generics in services, APIs, and reusable components.

---

# What

Generics allow us to write reusable code that works with different data types while maintaining type safety.

Without Generics:

```typescript
function getData(
    value: string
): string {

    return value;
}
```

Only string works.

---

With Generics:

```typescript
function getData<T>(
    value: T
): T {

    return value;
}
```

Works with:

```text
String
Number
Boolean
Object
Array
```

---

## Simple Meaning

```text
Write Once

Use With Multiple Data Types

Without Losing Type Safety
```

---

# Why

## Real-Life Analogy

Imagine a water bottle factory.

Without Generics:

```text
One Bottle For Water

One Bottle For Juice

One Bottle For Milk
```

Need separate designs.

---

With Generics:

```text
One Bottle Design

Can Hold Different Liquids
```

Reusable.

---

Similarly:

Without Generics:

```typescript
getStringData()

getNumberData()

getEmployeeData()
```

Multiple functions.

---

With Generics:

```typescript
getData<T>()
```

Single reusable function.

---

# How It Works

## Traditional Approach

```text
String Function
      ↓
Number Function
      ↓
Boolean Function
      ↓
Object Function
```

Many duplicate functions.

---

## Generic Approach

```text
Generic Function
      ↓
String
      ↓
Number
      ↓
Boolean
      ↓
Object
```

Single reusable function.

## Lab 7: Generic Class

```typescript
class DataStore<T> {

    private data: T[] = [];

    addItem(
        item: T
    ) {

        this.data.push(item);

    }

    getItems() {

        return this.data;

    }

}
```

Usage:

```typescript
let store =
    new DataStore<string>();

store.addItem(
    "Angular"
);

store.addItem(
    "TypeScript"
);

console.log(
    store.getItems()
);
```

Output:

```text
Angular
TypeScript
```

## Lab 9: Generic Constraint

### Problem

We want object only.

```typescript
function getLength<T>(
    item: T
) {

}
```

No restriction.

---

### Constraint

```typescript
function getLength<
T extends {
    length:number
}
>(
    item: T
) {

    return item.length;

}
```

Usage:

```typescript
console.log(
    getLength(
        "Angular"
    )
);
```

Output:

```text
7
```
